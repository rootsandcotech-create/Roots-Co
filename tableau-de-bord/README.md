# Tableau de bord ROOTS

Page de pilotage de ROOTS & Co : publications (texte, affiche, fiche, validation), projets et objectifs, reste à faire, radar d'événements, canaux, sécurité.

Les données sont chiffrées (AES-GCM) : sans le mot de passe de l'équipe, rien n'est lisible. Les affiches viennent du dépôt `roots-affiches`.

`schema.sql` : schéma MySQL de la version partagée (PHP et MySQL, pile décidée le 23/11/2026).

Mise à jour : le fichier `index.html` est régénéré après chaque travail (Log et Centralisation), puis poussé sur GitHub.
